福特Puma是福特自2019年起制造和销售的一款次紧凑型跨界SUV（B级），基于第七代嘉年华。
2019年在欧洲、2020年末在澳大拉西亚、2023年10月起在南非开始销售。欧洲市场Puma定位在翼搏之上、翼虎（欧洲以外也称锐际）之下。


== 概述 ==
福特最初在阿姆斯特丹Go Further活动上与第三代翼虎一同发布Puma跨界车。Puma铭牌上次用于Puma运动紧凑型车。车辆基于第七代嘉年华平台（福特全球B级车平台）。
2019年10月Puma在罗马尼亚克拉约瓦（福特罗马尼亚）与翼搏次紧凑型跨界车以及两车都用的EcoBoost 1.0升Fox发动机一同投产。福特投资2亿欧元，为该项目雇用1700人。
Puma提供轻度混动1.0升EcoBoost三缸涡轮增压汽油发动机，带皮带驱动集成启动机，利用制动系统能量给48伏锂离子电池充电，以提升扭矩、降低排放。额定功率153 bhp（155 PS）、114千瓦，扭矩240 N·m（180 lb·ft），集成启动系统再提供50 N·m（37 lb·ft）。
2022年12月Puma Vivid Ruby Edition作为新旗舰配置发布。
2023年3月Puma ST Powershift正式上市，配170 hp（130 kW）1.0升轻度混动发动机和自动变速箱。


== 改款 ==
2024年2月Puma做了较大改款，更新外观，含重做前格栅、新大灯和更窄保险杠设计；内饰也更新，含修订材料、更大信息娱乐屏和增强连接选项。为保持同级竞争力，车辆提供更高效发动机选择和创新驾驶辅助系统。


== Puma Gen-E ==

正如2022年已宣布的，Puma电动版Puma Gen-E于2024年12月3日上市。
这款紧凑型电动跨界SUV在罗马尼亚克拉约瓦的福特Otosan工厂生产，电驱动单元在英国福特Halewood工厂制造。它有让人想起更大Mustang Mach-E的设计元素，同时保持燃油Puma的较小车身。
车辆配备SK On供应的46.0千瓦时（可用43.6千瓦时）NMC锂离子电池组，电池为前置电机供电，输出123.5 kW（166 hp；168 PS）和290 N·m（210 lb·ft）扭矩，0到100 km/h（62 mph）加速8.0秒，最高车速160 km/h（99 mph）。Puma Gen-E WLTP综合续航在347—376 km（216—234 mi）之间，城市续航506—523 km（314—325 mi）。显著特征包括100千瓦直流快充，约23分钟充10–80%，以及把后备厢空间增至574公升（20.3立方英尺）的GigaBox地板下储物格，外加43-公升（1.5-立方英尺）前备厢。2025年春开始向欧洲客户交付。
上市时Puma Gen-E获得总体正面评价，Top Gear写道车“结果出奇地好”，Electrifying写道“它有实用性和价值，会很受欢迎”。Autocar给Puma Gen-E四星，因为“巨大后备厢、紧凑尺寸、出色实际效率和有趣动态让Puma Gen-E成为好选择”。
Puma Gen-E前悬架用麦弗逊支柱，后悬架用扭力梁。


== 安全 ==
Puma于2019年接受Euro NCAP测试，评级五星。成人和儿童保护分别评为94%和84%，Euro NCAP把行人安全评为77%。该组织2022年再次测试Puma，那次给综合四星，成人乘员75%、儿童乘员84%、弱势道路使用者70%、安全辅助69%。NCAP发现Puma在正面偏置碰撞中保护驾驶员胸部、全宽刚性屏障碰撞中保护后排成人乘客胸部，以及追尾中保护前排人员免受挥鞭伤方面表现“一般”，在防止碰撞中乘员身体左右甩动方面表现“差”，其他成人乘员领域总体表现良好。他们还发现儿童乘员保护在所有测试中“良好或足够”，被撞行人保护除挡风玻璃底部及周围A柱（被描述为“硬”、头部保护“差”）外所有区域“良好或足够”。NCAP因前排座椅和头枕在低速自动紧急制动测试中的特征，把自动紧急制动系统表现评为“一般”。
车可选带行人检测的预碰撞辅助、紧急制动辅助、胎压监测、电子稳定控制、半自动泊车辅助和紧急转向辅助，还有自适应巡航，其他可选特征有自动紧急制动、智能限速和车道保持辅助。

== 反响 ==
2020年1月《What Car?》杂志把Puma评为年度汽车。2021年1月Puma 1.0 Ecoboost Hybrid 155 Titanium赢得《What Car?》年度小型SUV称号，同年Puma ST 1.5 Ecoboost 200 Performance Pack被该杂志评为年度运动SUV。《What Car?》在评测中给Puma五星满分。
2020年《星期日泰晤士报》发现信息娱乐系统比一些竞争大众集团产品更难操作，指出Puma后排乘客空间比那些车型小，但觉得大窗户意味着孩子坐后排比在日产Juke或丰田C-HR里更不易晕车。他们觉得高速时内饰相对安静，但发现乘坐质量略逊于一些竞争对手，把456-公升（16.1-立方英尺）后备厢列为当时所售跨界车中最大之一。同一出版物还评测ST车型，称“不确定为什么要选它而不是153马力ST Line Puma”，指出“不舒服座椅和敏感操控在SUV里不太合理”，同时称平均31英里每英制加侖（9.1公升每100公里；26英里每美制加侖）对静止6.7秒破62英里/时的车来说“不错”。《每日电讯报》发现所测Titanium车型实体按键比一些同期车的触控板更不分心。两家报纸都称赞Puma离合和刹车，并把后备厢下可排水的megabox列为突出特征。《Which?》发现换电台“没必要地复杂”，调查中发现Puma可靠，研究时段内50辆四年以下Puma中1辆抛锚。


== 福特Puma Rally1 ==

一款名为福特Puma Rally1的Rally1组赛车自2022年起参加世界拉力锦标赛。它基于福特Puma跨界车公路版，为取代2017至2021年参赛的福特嘉年华WRC而开发。车在2021年古德伍德速度节亮相。


== 销量 ==
2021年福特Puma超过嘉年华成为英国最畅销福特车型，高销量还使它成为2021年英国总销量第八车型，全年新增注册28,697辆。Puma成为2022年英国第四畅销车，并在2023、2024、2025年成为英国最畅销车，还是2023年欧洲第八畅销车。
