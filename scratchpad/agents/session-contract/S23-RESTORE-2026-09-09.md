## Limits and harness notes

- `n=4` was requested, but cycle 1 completed immediately before temperature reached 42.7 C / Thermal Status 3; the app was force-stopped and no further cycle was attempted.
- The official share deep link (`am start VIEW kalsa://share?...`) backgrounds RN/AppState and can trigger `disposeEngine`; this build did not reliably transfer the initial URL into the React draft. A clean two-message seed was made through RKStorage, then the continuation used the visible template/send controls. This preserves the reopened-chat engine path but is not a share-intent UI measurement.
- Wireless ADB and the S23-only target filter were used; the Xiaomi and Jelly serials were not addressed. No charger was connected.
