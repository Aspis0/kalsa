## Stage 1 — the 20 s gap vs tonight's own numbers (semantics, fatal flaw)

- **CONFIRMED (design flaw): the watchdog would NOT have aborted tonight's turn.** stallWatchdog.ts:8 `export const GENERATION_STALL_GAP_MS = 20_000;` — but tonight's collapse was 15 tokens in 259.7 s = **17.3 s mean inter-token gap**, below the 20 s threshold. A paging-thrashed decode is bursty (page-fault storms), so gaps straddle 20 s nondeterministically; the exact incident that motivated fix ① sits just under the trip wire. A fixed 20 s gap also means a healthy-but-slow model (≤0.05 tok/s sustained) can never finish a long answer. The gap should scale off the turn's own measured decode rate (the `predictedPerSecond` from round 1 / deviceThroughput store), not a constant.
- **CONFIRMED (coverage hole): prefill is unwatched.** Arm sites are inside the token callback only — LlamaService.ts:3339-3341 `stallWatchdog.noteToken(); stallTokenCount += 1; startStallWatchdog();` and the fallback round :3683-3685. `check()` returns not-stalled while `lastTokenAt === null` (stallWatchdog.ts:27), and `startStallWatchdog()` only arms on first token — so a 286 s prefill (tonight's other half) runs to completion with no deadline. By the brief ("armed only after first token") this is intended, but it means fix ① covers only the decode half of the S23 incident.
- **REFUTED (reasoning-token false stall): safe.** noteToken() runs unconditionally on EVERY TokenData callback — LlamaService.ts:3337-3341 — BEFORE the `const raw = data.token ?? ""` / `cleanStreamDelta(raw)` filtering at :3345-3347. Think-tag content arrives as data.token (rawEmittedAccum even accumulates it, :3346), so a long thinking phase keeps resetting the watchdog. No false stall during thinking.

- **CONFIRMED (new, real bug): double `onModelEmittedText` + double abort body.** `abort()` is no longer single-shot: checkStall can call `abort(error)` (:2864) and the signal listener `onAbort = () => abort()` (:2891) can fire afterwards (listener is removed only in the `finally`, and `{ once: true }` only dedupes signal events, not the two call sites). In abort() the `onModelEmittedText` emission is OUTSIDE finishOnce — LlamaService.ts:2832-2835:
  > if (rawEmittedAccum) {
  >   callbacks.onModelEmittedText?.(rawEmittedAccum);
  > }
  > finishOnce(() => (error ? callbacks.onError(error) : callbacks.onDone()));

Downstream it's mostly idempotent (AiChatPage.tsx:2427-2433 `modelEmittedText = text` overwrite, same value), but it is an unguarded duplicate side effect on a path the old code could not reach (old abort had one caller). - Double onError: finishOnce is one-shot (:2824-2828), emitEngineError routes through finishOnce (LlamaService.ts:2022). No double onError. REFUTED.
- Interval self-termination on a hung completion: if the native promise never settles, checkStall fires after 20 s, stops the timer itself, aborts. Worst-case leak ≈ one tick. REFUTED as a leak.
