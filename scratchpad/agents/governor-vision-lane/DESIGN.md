# Governor vision lane — design sketch (read-only recon; owner decision: option 3)

mmproj models (Qwen3.5-4B, then LFM2.5-VL) stay OUT of the governor until it has a real
vision lane. No lazy-mmproj. Path prefixes: engine = kalsallama, binding = llama.rn-kalsa, app = kalsa.

## 1. How the governor moves state between its two contexts today

- Two independent contexts, independent caches: `src/llama-governor.cpp:34:     if (params_prefill.ctx_other || params_decode.ctx_other) {` → `src/llama-governor.cpp:35:         throw std::runtime_error("governor contexts must have independent KV caches");`

## 4. Traps

- **M-RoPE / positions:** image positions are 4-section (`tools/mtmd/mtmd-helper.cpp:139`) but section 0 is contiguous (`tools/mtmd/mtmd.cpp:2509`), so `sequence_end` (`src/llama-governor.cpp:71:     const llama_pos max_pos = llama_memory_seq_pos_max(llama_get_memory(ctx), seq_id);`) works **only if** KV cells key on section-0 t — verify before relying on the [watermark,end) copy (`src/llama-batch.cpp:781:         for (size_t j = 0; j < (size_t)n_pos_per_embd; ++j) {` packs all n_pos sections). Also processMedia's prefix math (`cpp/rn-mtmd.hpp:469:             n_past = find_common_prefix_length(embd, all_tokens);`) must agree with the governor watermark, or `end < src.watermark` fails the handoff (`src/llama-governor.cpp:93:         LLAMA_LOG_ERROR("%s: %s watermark is invalid\n", __func__, direction);`)
- **LFM recurrent/conv state:** handed off wholesale, ignoring (p0,p1): `src/llama-hybrid-commit.cpp:69:     dst.cells = src.cells;` … `:74:     dst.rs_z = src.rs_z;`. Image tokens update R/S during prefill, so the copy is correct at handoff — but rewind is not: `cpp/rn-mtmd.hpp:683:     // Don't trim to L-1 and re-decode the last token: seq_rm can't roll back a` / `cpp/rn-mtmd.hpp:684:     // recurrent/hybrid state (it no-ops), so the token would be consumed twice.` → mid-turn media re-trims (`cpp/rn-mtmd.hpp:536:     bool clear_result = llama_memory_seq_rm(kv, seq_id, n_past, -1);`) must be forbidden under governor (fail fast at load, like `cpp/rn-llama.cpp:1141` does today).
- **Non-causal flip:** `tools/mtmd/mtmd-helper.cpp:166-167` toggles `llama_set_causal_attn(lctx, false)` mid-turn; under governor `lctx` must be the ctx the governor will decode on, and the two ctx graphs must flip together or the handoff sees mismatched graphs.
- **Thermal admission:** a 512-token image chunk (`src/engine/LlamaService.ts:2703:           image_max_tokens: 512,`) is one prefill row; `Wait` pauses the turn (`src/llama-governor-runtime.cpp:56:         LLAMA_LOG_WARN("%s: no safe prefill chunk under the thermal ceiling; pausing\n", __func__);`), and `Abort` fails it (`:51:         return fail("prefill admission aborted");`). seq-0-only is enforced (`src/llama-governor.cpp:172:                 return fail("governor supports sequence 0 only");`).
