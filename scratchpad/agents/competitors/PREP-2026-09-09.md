No `.tflite` files are present. The repo is Apache-2.0, public, and not gated. No model config JSON is required by the README/import UI: settings are entered in Gallery’s import dialog.

The downloaded pure-int4 file is the closest overall weight-quant match to GGUF Q4_K_M; it is the README’s phone file and supports CPU+GPU. The CPU-only alternative is mixed int4/int8 (`wi4c_wi8_afp32`), not a pure 4-bit weight file.

Import: `adb push /local/MiniCPM5-2B_int4.litertlm /sdcard/Download/`; in Gallery open Model manager → `+` → **From local model file**; choose the file in Downloads, set/record name, LLM type, max tokens, sampling, thinking/image/audio flags, and compatible accelerators; tap **Import**. The alternative **Import from HF** accepts the model card or direct `.litertlm` URL but requires HF login and network.

## Noema documentary review (not run; 13 lines)

- Platforms: native iPhone/iPad (iOS/iPadOS 18+, A12+), Apple-silicon Mac (macOS 26+), and Vision Pro (visionOS 26+); no Android client.
- Explore → Models selects a compatible file/quantisation and shows RAM fit, size, context, capabilities, dependencies, publisher, provenance, and licence; Stored is the ready/loaded state.
- Supported downloads include GGUF, MLX, ExecuTorch, and Core ML; Apple Foundation Models are OS-supplied.
- Supported interrupted downloads resume; Noema 3.8 explicitly presents Pause, Resume, and Stop controls. This was not interactively verified.
- If loading fails, docs point to memory-heavy apps, smaller/lighter quantisation, reduced context/Battery Saver, and Settings → Diagnostics & Tools; download errors include insufficient storage, incompatible file, or missing projector/dependency.
- Attach PDF/EPUB/Markdown/text/JSON/JSONL; extraction/indexing status is shown inline. Retrieval requires a separate embedding model, then chunking/embedding/index completion; Dataset Health diagnoses stale/incomplete indexes.
- RAG supports datasets/Knowledge Packs, retrieval receipts, source passages/citations, and Dataset Search; citations still require human checking.
- Tools include local Python (offline, sandboxed), web search, calculator/unit converter, memory, charts, voice/media, MCP, and device integrations; availability is model/permission/network dependent.
- Noema Overfit stores `resident.gguf`, paged `experts-*.bin`, and `manifest.json`; Automatic mode plus Canary Test measures load, TTFT, speed, stalls, memory, thermal state, and expert-bank misses.
- Local chat/retrieval/tools can work offline; downloads, web search, remote endpoints, Constellation, and remote speech need network. Off-grid Mode blocks external HTTP(S).
- Pricing: personal app is free with no subscriptions, in-app purchases, paywalls, or usage caps; Noema Teams is separate paid enterprise service.
- Licence: Noema’s own code is MIT per Credits; app EULA applies, and model bundles retain mixed upstream licences (e.g. Apache-2.0/MIT). Overfit is a runtime/package format, not a new model licence.
