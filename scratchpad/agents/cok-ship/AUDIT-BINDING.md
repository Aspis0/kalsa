## 3. The fix's default in the vendored copy — CONFIRMED

`vendor/.../ggml-opencl.cpp:1587-1600`:

```
inline bool kalsa_cok_acc_f32() {
    static const bool value = [] {
        const char * e = getenv("KALSA_COK_ACC");
        if (e && strcmp(e, "fp16") == 0) { return false; }
        if (e && *e && strcmp(e, "fp32") != 0) {
            GGML_LOG_ERROR("ggml_opencl: unrecognized KALSA_COK_ACC='%s' (use fp32|fp16)\n", e);
            exit(1);
        }
        return true;
    }();
    return value;
}
```

`:4482-4487` adds the define only for the fp16 arm:

```
const bool cok_acc_f32 = kalsa_cok_acc_f32();
std::string cok_opts = compile_opts;
if (!cok_acc_f32) { cok_opts += " -DKALSA_COK_ACC_F16"; }
... build_program_from_source(backend_ctx, kernel_src.c_str(), cok_opts);
```

Kernel: `#ifdef KALSA_COK_ACC_F16` → `half8 acc = 0;` / `acc += B * dq;`; `#else` → `float8 acc = 0;`
/ `acc += convert_float8(B) * (float)dq;` (`.cl:428-434`, `:459-465` and the three sibling
quadrants). No env var → `#else` f32 arm. `KALSA_COK_ACC=fp16` → the define → the half control arm.
An empty value (`e && *e` false) also yields f32.

**The program cache cannot defeat the switch.** `cl-program-cache.cpp:156-172 compute_key` hashes
`source`, `compile_opts`, and `key_suffix`; `try_load`/`try_save` are called with the same
`cok_opts` (`ggml-opencl.cpp:1437-1453`), so fp16 and fp32 are distinct cache entries and a cached
binary built under one arm cannot be served for the other. The `.cl.h` embedded path is generated
at build time (`#ifdef GGML_OPENCL_EMBED_KERNELS` + `#include "...q4_k_f32.cl.h"`) and no generated
header is tracked, so the source change reaches both load paths.
