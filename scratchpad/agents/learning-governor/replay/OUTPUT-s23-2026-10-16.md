- residual sigma 0.5398 C, max |residual| 0.6479 C (sigma floor 0.2 C, outlier cut max(1.0 C, 3 sd), both from DESIGN 5.6)

**The condition-number convention**, because the number is meaningless without it: each predictor column is scaled to unit L2 norm and the intercept column is left at 1; the reported figure is the 2-norm condition number of THAT design matrix. The Gram ratio printed beside it is its square - an eigen-decomposition of X'X yields squared singular values, so a reader comparing against a design-matrix figure wants the square root.

**OPEN 6 verdict.** The design is FULL RANK (6 of 6 columns, 10 rows, 4 residual degrees of freedom) - no column is mathematically unidentifiable here - but it is ILL-CONDITIONED: condition number 376.8 against 30.6 without the cooling column. Dropping the cooling column moves `npu_k` from 3.682 to 5.233 C per 1k tokens and `wall_min` from 1.895 to -1.759 C per minute, so the cooling term and the token/time columns are fighting over the same variance: the individual coefficients are UNSTABLE ESTIMATES and none of them should be read as a heat number yet. cpu_k, prefill_gpu_k carry no variance on these rows and are reported as not identifiable; Stage 0 rows do not spend those tokens, so no Stage 0 row set will fix that.
