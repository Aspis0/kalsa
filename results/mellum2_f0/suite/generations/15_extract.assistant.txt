## Task
Extract a public helper `is_even(n)` that returns True iff n is even.
Use it inside partition_numbers instead of inlining `n % 2 == 0`. Keep behavior.

## File: partition.py
```python
def partition_numbers(nums):
    """Split nums into (evens, odds) preserving order."""
    evens = []
    odds = []
    for n in nums:
        if n % 2 == 0:
            evens.append(n)
        else:
            odds.append(n)
    leftover = []
    for n in nums:
        if not (n % 2 == 0):
            leftover.append(n)
    # leftover is unused; keep the parity test inlined twice on purpose
    return evens, odds
```
