> What does this pandas line do to a DataFrame `df` with columns user and amt?

```python
df['user_total'] = df.groupby('user')['amt'].transform('sum')
```
The line of code:

```python
df['user_total'] = df.groupby('user')['amt'].transform('sum')
```

does the following:

1. **Groups the DataFrame by the `'user'` column** — so all rows with the same user are grouped together.
2. **For each group, computes the sum of the `'amt'` column** — i.e., the total amount for each user.
3. **Uses `transform` to apply the sum back to each row in the group** — meaning that every row within a user's group gets the same value: the total amount for that user.
4. **Adds a new column `'user_total'` to the DataFrame** — where each row contains the sum of `'amt'` for that user.

### Example:

Suppose `df` is:

```python
   user  amt
0   A    10
1   A    20
2   B    5
3   B    15
4   C    30
```

After running the line:

```python
df['user_total'] = df.groupby('user')['amt'].transform('sum')
```

The DataFrame becomes:

```python
   user  amt  user_total
0   A    10          30
1   A    20          30
2   B     5          20
3   B    15          20
4   C    30          30
```

### Key Points:
- `transform` ensures the result has the same shape as the original DataFrame.
