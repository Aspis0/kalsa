A Mixture-of-Experts (MoE) language model works by splitting a large neural network into many smaller “expert” components, with a lightweight “router” that looks at each input token and decides which few experts are most relevant for that token, so only those selected experts (and the rest of the weights for them) are activated to produce the output, which is why even though the model can keep a massive total amount of parameters on disk, a phone only needs to load and run the much smaller set of experts that the router selects for each token, a technique called routing that also enables efficient “flash streaming” of only the necessary expert weights from storage so that memory and compute are used only where needed; this is why the on‑disk weight file can stay large (to store all the experts) while the active compute and memory for a single token is reduced.
