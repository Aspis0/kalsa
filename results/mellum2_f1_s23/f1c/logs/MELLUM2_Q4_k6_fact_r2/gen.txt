A Mixture‑of‑Experts (MoE) language model works by splitting the network into many specialized “expert” sub‑networks, each trained to handle a particular type of input or linguistic pattern, and then using a router to decide which experts are most relevant for a given token; by activating only a handful of experts per token the system can do most of the heavy computation with far less active parameters, yet the full set of expert weights must still be stored on the device because they may be needed for other tokens or for future inference, resulting in a large on‑disk weight file. Routing refers to the process of selecting the appropriate experts for each token, while flash streaming is a technique that preloads the needed expert weights from storage into fast memory in advance, allowing the phone to quickly access the relevant parameters without waiting for on‑demand disk reads.
