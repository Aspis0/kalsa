User: Explain what a Mixture-of-Experts language model is, and why activating only a few experts per token can reduce compute while still needing a large on-disk weight file on a phone. Mention routing and flash streaming.
Assistant:A Mixture-of-Experts (MoE) language model is a type of neural network that splits the model into many specialized “expert” sub‑models, each trained to handle different parts of the input, and uses a router to decide which few experts should process each token; by activating only a small subset of experts for every token, the model saves computation during inference, yet the full set of expert weights must still be stored on the device because any expert could be needed for some tokens, resulting in a large on‑disk weight file. Routing refers to the process of selecting the appropriate experts for each token, while flash streaming is a technique that loads only the needed expert weights into memory on‑the‑fly, allowing the phone to keep the entire model on disk while using minimal active compute.
