A Mixture-of-Experts (MoE) language model is a system where a single token is processed by only a subset of specialized "expert" sub-networks, while the rest remain inactive. This approach drastically reduces the active computation per token because the model does not need to calculate the full output for every single token, effectively lowering the per-token compute cost. However, this efficiency comes at the cost of a massive on-disk weight file because the model must store the parameters for all experts, even though only a fraction are used during inference.

*   **Routing**: This mechanism directs the token to the specific expert that provides the best prediction, ensuring that the selected experts are optimized for the current input context.
*   **Flash Streaming**: This technique allows the model to stream the output from the active experts directly to the output buffer without storing the entire intermediate activations in memory, which is crucial for running on devices with limited RAM.
