A Mixture‑of‑Experts (MoE) language model splits the network into many specialized “expert” sub‑networks, each trained to handle different parts of the language, and uses a router to decide which few experts should be activated for any given token; this selective activation cuts the amount of computation needed per token, yet the full set of expert weights must still be stored on the device because the router and the unused experts are required for accurate routing and future inference, resulting in a large on‑disk weight file. To keep the phone’s memory usage low while still accessing these many weights, the system employs flash streaming, which loads only the needed expert weights into RAM on‑the‑fly from storage as they are activated, allowing the device to run a large MoE model without exceeding its memory limits.
