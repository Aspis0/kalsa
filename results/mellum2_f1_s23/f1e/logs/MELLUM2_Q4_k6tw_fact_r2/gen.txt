A Mixture‑of‑Experts (MoE) language model works by splitting the network into many specialized “expert” sub‑networks, each trained to handle a particular type of input or linguistic pattern, and then using a router to decide which few experts should be activated for any given token; this selective activation means the phone only needs to compute a small subset of the full model at any moment, saving processing power, yet the entire collection of expert weights must still be stored on‑disk because the router may need to reference any expert when processing different tokens, and techniques like flash streaming can pre‑load only the experts that are likely to be used soon, keeping the active memory footprint low while the model file remains large.
