A Mixture‑of‑Experts (MoE) language model splits the network into many specialized “expert” sub‑networks, each trained to handle different parts of the language, and uses a router to decide which few experts should process each token; by activating only a small subset of experts for every token, the model saves compute during inference, yet the full set of expert weights must still be stored on the device because the router and any needed expert parameters can be streamed from disk on‑demand, a technique called flash streaming that loads only the required weights into memory while keeping the overall model file large.
