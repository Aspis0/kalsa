A Mixture-of-Experts (MoE) language model uses a network of specialized “expert” neural networks, each trained for a specific task or pattern, and activates only a subset of these experts per token to reduce compute. This is achieved through a routing mechanism that selects the most relevant experts for each input, and the model’s weights are stored as a large on-disk file because the full set of expert parameters must be loaded, even if only a few are used per token. Flash streaming allows the model to process tokens incrementally, loading only the necessary experts from disk as needed, which reduces memory usage and enables efficient inference on devices like phones. The routing mechanism dynamically selects experts, and the system can stream only the required experts for each token, minimizing compute and memory footprint.

- The model activates only a few experts per token (e.g., 4–8 out of 100+), drastically reducing FLOPs during inference.  
- The full weight matrix is stored
