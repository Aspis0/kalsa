User: Explain what a Mixture-of-Experts language model is, and why activating only a few experts per token can reduce compute while still needing a large on-disk weight file on a phone. Mention routing and flash streaming.
Assistant:A Mixture-of-Experts (MoE) language model is a type of neural network that dynamically activates only a subset of specialized “expert” networks for each token, allowing it to scale efficiently without processing all experts for every input. This selective activation reduces compute because only a few experts are used per token, even though the model has thousands of them. The large on-disk weight file exists because the full model—every expert’s weights—are stored on disk, and the system must load the entire model to serve inference, even if only a few experts are used at runtime. Routing mechanisms decide which experts to activate, and flash streaming enables fast, incremental loading of the active experts from storage, minimizing memory usage and enabling efficient deployment on devices like phones.

- Only a few experts are activated per token, reducing FLOPs and memory usage during inference.  
- The full model weights are stored on disk, and flash streaming loads only the active experts on-demand to minimize memory footprint.
