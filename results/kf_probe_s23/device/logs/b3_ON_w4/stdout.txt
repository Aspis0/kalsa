User: Explain what a Mixture-of-Experts language model is, and why activating only a few experts per token can reduce compute while still needing a large on-disk weight file on a phone. Mention routing and flash streaming.
Assistant:A Mixture-of-Experts (MoE) language model is a type of neural network that dynamically activates only a subset of specialized “expert” networks for each token, allowing it to scale efficiently without processing all experts for every input. This selective activation reduces compute because only a few experts are used per token, even though the model has thousands of them. The large on-disk weight file exists because the full model—thousands of expert parameters—is stored, but only a small portion is used at inference time. Routing mechanisms determine which experts to activate, and flash streaming enables fast, low-latency access to the active experts during inference, making it feasible for mobile devices to run large models without excessive memory or compute overhead.

- Routing layers select the most relevant experts for each token, minimizing computation while preserving performance.  
- Flash streaming allows the model to load and activate only the necessary expert parameters on-demand, reducing memory usage and enabling efficient inference on mobile hardware.
