A Mixture-of-Experts (MoE) language model uses many specialized "expert" networks, each trained for a specific task or pattern, and activates only a subset of them for each token to save compute. This is done by routing the input to a small number of active experts, which reduces the number of parameters evaluated per token. The model’s weights are stored in a large on-disk file because the full set of expert parameters is still needed to represent the model, even though only a few are used at inference time. Routing mechanisms (like attention or gating networks) decide which experts to activate, and flash streaming allows the model to process tokens incrementally, using only the necessary experts as they arrive, making it feasible on devices like phones.
