A Mixture-of-Experts (MoE) language model is a type of neural network that dynamically activates only a subset of specialized "expert" networks for each token, allowing it to scale efficiently without processing all experts for every input. This selective activation reduces compute because only a few experts are used per token, even though the model has thousands of them. The large on-disk weight file exists because the full model—every expert’s weights—are stored, but only the active ones are used during inference. Routing mechanisms determine which experts to activate, and flash streaming enables fast, low-latency access to the relevant expert weights, making it feasible to run on devices like phones without requiring full model loading.

- Only a few experts are activated per token, drastically cutting compute during inference.  
- The full model’s weights are stored on disk, but routing and flash streaming allow efficient, on-demand access to the active experts without loading the entire model into memory.
