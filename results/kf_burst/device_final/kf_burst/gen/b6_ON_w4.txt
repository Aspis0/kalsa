A Mixture-of-Experts (MoE) language model is a type of neural network that dynamically activates only a subset of specialized "expert" networks for each token, allowing it to scale efficiently without processing all parameters for every input. This selective activation reduces compute during inference because only a few experts are used per token, even though the model has thousands of parameters. The large on-disk weight file exists because the full model—every expert’s weights—are stored, and the system must still load and manage these weights for routing and inference, even if only a few are used at a time. Routing mechanisms determine which experts to activate, and flash streaming enables fast, low-latency access to the necessary weights during inference, allowing the model to operate efficiently on resource-constrained devices like phones.
