A Mixture-of-Experts (MoE) language model is a type of neural network that dynamically activates only a subset of specialized “expert” networks for each token, allowing it to scale efficiently without processing all experts for every input. This selective activation reduces compute because only a few experts are used per token, even though the model has thousands of experts. The large on-disk weight file exists because the full model—thousands of expert parameters—is stored on disk, and the system must load the entire model into memory for inference, even if only a few experts are used at a time. Routing mechanisms decide which experts to activate, and flash streaming enables fast, low-latency access to the relevant expert weights as the model processes tokens sequentially, minimizing memory usage and enabling efficient deployment on devices like phones.
