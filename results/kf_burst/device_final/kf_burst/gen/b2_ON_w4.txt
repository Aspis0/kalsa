A Mixture-of-Experts (MoE) language model uses a network of specialized “expert” neural networks, each trained for a specific task or pattern, and routes input tokens to the most relevant experts via a lightweight routing mechanism. Activating only a few experts per token—instead of all of them—dramatically reduces the number of parameters evaluated per forward pass, cutting compute and memory usage, which is crucial for mobile deployment. However, because the model still stores all expert weights on disk (e.g., in a large on-disk weight file), the total size remains large, even though only a subset is used per token. Routing is typically implemented via a gating network that selects the top-k experts, and flash streaming allows the model to load and activate only the necessary experts in real time, minimizing memory pressure while maintaining performance.
