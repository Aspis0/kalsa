User: Explain what a Mixture-of-Experts language model is, and why activating only a few experts per token can reduce compute while still needing a large on-disk weight file on a phone. Mention routing and flash streaming.
Assistant:A Mixture-of-Experts (MoE) language model uses a network of specialized “expert” subnetworks, each trained for a specific task or pattern, and activates only a subset of them for each token to save compute. Instead of using the full model for every token, the model routes the input to a small number of active experts—often just one or two—based on a routing mechanism that selects the most relevant ones. This allows the model to maintain a large total parameter count (e.g., hundreds of billions) while only computing on a fraction of the weights per token, reducing inference cost. The large on-disk weight file is stored as a complete, uncompressed model, because the experts are trained independently and the routing network (which is small and lightweight) is not stored separately. Flash streaming and dynamic routing allow the model to load only the necessary experts for each token, enabling efficient on-device inference without needing to load the entire model at once.
