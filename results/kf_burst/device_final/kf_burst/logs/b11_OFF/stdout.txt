Instead of using all experts for every input, the model routes the token to a few relevant experts via a lightweight routing mechanism, which is learned during training. This allows the model to be large and powerful while keeping inference efficient. The weights are stored in a single large on-disk file because the full model parameters are still needed for the experts, even if only a few are activated per token.
