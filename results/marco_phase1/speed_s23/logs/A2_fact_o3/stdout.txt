User: Explain what a Mixture-of-Experts language model is, and why activating only a few experts per token can reduce compute while still needing a large on-disk weight file on a phone. Mention routing and flash streaming.
Assistant:A Mixture-of-Experts (MoE) language model uses a router to select only a few of its many “experts” (specialized sub-networks) to process each token, which dramatically reduces computation compared to dense models. Even though only a few experts are activated per token, the model still needs to store all the expert weights on disk because the full set of experts is required to handle any input — this results in a large on-disk weight file. The router routes each token to the most relevant experts, and flash streaming allows the model to fetch and activate only the necessary experts in real time, minimizing memory usage and enabling efficient inference on devices like phones.

- The router dynamically selects a small subset of experts per token, reducing FLOPs and memory usage during inference.  
- Flash streaming enables efficient, incremental processing by loading and activating only the required expert weights on-demand, allowing large MoE models to run on mobile devices.
