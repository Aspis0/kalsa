Assistant:A Mixture-of-Experts (MoE) language model uses a gating network to route each token to only a few of its many specialized “expert” sub-networks, allowing it to scale up capacity without proportional compute cost. By activating only a handful of experts per token, the model dramatically reduces inference latency and memory usage, even though the total number of parameters (and thus the on-disk weight file) remains large—because all experts are stored, but only a subset is used per token. This is enabled by efficient routing (e.g., top-k or sparsely activated gates) and flash streaming, where the model can load only the relevant expert weights from storage on-demand, avoiding the need to load the entire model into RAM.

- The full weight file is stored on disk, but only the relevant expert weights are streamed into memory for each inference step.
