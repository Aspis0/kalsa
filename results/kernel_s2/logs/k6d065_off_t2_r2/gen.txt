User: Explain what a Mixture-of-Experts language model is, and why activating only a few experts per token can reduce compute while still needing a large on-disk weight file on a phone. Mention routing and flash streaming.
A Mixture‑of‑Experts (MoE) language model works by splitting the network into many specialized “expert” sub‑networks, each trained to handle a particular type of input or linguistic pattern, and then using a router to decide which experts should be consulted for a given token; by activating only a handful of experts per token the system does far less actual computation, yet the full collection of expert weights must still be stored on the device because they are needed on‑demand, resulting in a large on‑disk weight file. Routing refers to the process of selecting the relevant experts for each token, while flash streaming is a technique that preloads the required expert weights from storage into fast memory just before they are needed, allowing the phone to keep the model’s total size big enough to retain all expertise while keeping runtime compute low.
