A Mixture-of-Experts (MoE) language model uses many specialized sub-networks called "experts" to process different parts of the input, allowing the model to be large and powerful without being fully active for every token. Instead of activating all experts for every token, only a few are selected based on the input, which reduces compute during inference. This is possible because the model’s weights are stored in a compact, sparse format, and the routing mechanism decides which experts to activate. On devices like phones, the model’s weights are stored in a large on-disk file because the full weight matrix is still needed to represent the model’s architecture, even though only a subset is used per token. Flash streaming allows the model to load and use only the necessary experts in real time, minimizing memory usage and enabling efficient inference on limited hardware.

- Only a small number of experts are activated per token, reducing FLOPs and memory usage during inference.  
- The full weight matrix is stored
