A Mixture-of-Experts (MoE) language model is a type of neural network that dynamically activates only a subset of specialized “expert” networks for each token, allowing it to scale efficiently without processing all parameters for every input. This selective activation reduces compute during inference, as only a few experts are used per token, which is especially useful on devices with limited memory like phones. The model’s weights are stored in a large on-disk file because the full set of expert parameters must be saved to support training and inference, even though only a small fraction is used per token. Routing mechanisms determine which experts to activate, and flash streaming enables fast, low-latency access to the relevant experts during inference, allowing the model to remain efficient and compact on mobile hardware.
