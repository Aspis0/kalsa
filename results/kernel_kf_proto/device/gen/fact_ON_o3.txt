A Mixture-of-Experts (MoE) language model uses a network of specialized “expert” subnetworks, each trained for a specific task or pattern, and activates only a subset of them for each token to save compute. Instead of using the full model for every inference, the model routes the input to a small, randomly selected group of experts, which are then used to compute the output. This allows the model to maintain a large total parameter count (e.g., hundreds of billions of weights) while only activating a few dozen experts per token, drastically reducing inference cost. The large on-disk weight file is stored because the full model weights are still needed to represent the expert networks, even if only a fraction are used at runtime. Routing is done via a lightweight “gate” network that decides which experts to activate, and flash streaming enables efficient, low-latency access to the weights by loading only the necessary expert parameters into memory as needed, rather than loading the entire model at once
