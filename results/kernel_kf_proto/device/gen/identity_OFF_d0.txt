A Mixture-of-Experts (MoE) language model is a type of neural network that dynamically activates only a subset of specialized “expert” networks for each token, rather than using all experts for every input. This allows the model to be much larger than what fits in memory, while still being efficient during inference. Activating only a few experts per token reduces compute because only the selected experts are used, and the rest remain inactive. The large on-disk weight file exists because the full model—every expert’s weights—are stored, even though only a few are used per token. Routing mechanisms decide which experts to activate, and flash streaming enables fast, low-latency access to these weights by loading only the necessary parts of the model as needed, minimizing memory usage on devices like phones.
