A Mixture-of-Experts (MoE) language model uses many specialized "expert" networks, each trained for a specific task or pattern, and activates only a subset of them for each token to save compute. Instead of using all experts for every input, the model routes the token to a few relevant experts via a lightweight routing mechanism, which is learned during training. This allows the model to be large and powerful while keeping inference efficient. The weights are stored in a single large on-disk file because the full model parameters are still needed for the experts, even if only a few are activated per token. Routing is typically done using a sparse attention or gating mechanism, and flash streaming enables the model to process tokens in real time by loading only the necessary expert weights from disk as needed, reducing memory pressure on mobile devices.
