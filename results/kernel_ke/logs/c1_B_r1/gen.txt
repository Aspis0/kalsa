User: Explain what a Mixture-of-Experts language model is, and why activating only a few experts per token can reduce compute while still needing a large on-disk weight file on a phone. Mention routing and flash streaming.
A Mixture‑of‑Experts (MoE) language model works by splitting the network into many specialized “expert” sub‑networks, each trained to handle a particular pattern or style, and a lightweight “router” that looks at each incoming token and decides which few experts are most relevant for that token; because only those selected experts need to be evaluated, the amount of real‑time computation (compute) can be kept low, yet the full collection of expert weights must still be stored on the device so the router can consult them when it makes its decision. Routing refers to the process by which the router selects the appropriate experts for a given token, while flash streaming is a technique that loads only the portions of the large weight file that are currently needed into fast memory, allowing the phone to keep the on‑disk model size large while still operating efficiently.
