A Mixture-of-Experts (MoE) model consists of multiple distinct neural network "experts" that are selectively activated for each input token via a routing mechanism, allowing the system to scale capacity without increasing the compute cost of every forward pass. While this sparse activation significantly reduces the processing power and energy required during inference, the entire model must still be downloaded to the device because the on-disk storage size is determined by the sum of all experts, not just the active subset.

*   **Routing and Compute Efficiency**: A gating network determines which specific experts handle each token, enabling "sparse" activation where only a small fraction of the total parameters are computed per step, thereby lowering latency and power consumption on mobile hardware.
