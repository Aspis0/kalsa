A Mixture-of-Experts (MoE) model consists of multiple distinct neural network "experts" that are selectively activated for each token based on a routing mechanism, which directs data to the most relevant experts to maximize efficiency. Although this sparse activation significantly reduces the actual computation and memory bandwidth required during inference, the entire model must still be downloaded to the device because the on-disk weight file contains all experts to ensure the model can handle diverse inputs, and flash streaming allows the system to load only the necessary small portions of these weights into fast memory on demand.
