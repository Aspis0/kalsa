A Mixture-of-Experts (MoE) language model uses many specialized "expert" networks, each trained for a specific task or pattern, and activates only a subset of them for each token to save compute. This is done by routing the input to a small number of active experts, which reduces the number of parameters processed per token. The model’s weights are stored in a large on-disk file because the full set of expert parameters is still needed to represent the model, even though only a few are used per inference. Routing mechanisms decide which experts to activate, and flash streaming allows the model to process tokens in a streaming fashion, loading only the necessary expert weights on the fly, which is critical for mobile devices with limited memory.

- Only a few experts are activated per token, reducing FLOPs and memory usage during inference.  
- The full set of expert weights is stored on disk, enabling efficient loading and routing without requiring the entire model to be resident in RAM.
