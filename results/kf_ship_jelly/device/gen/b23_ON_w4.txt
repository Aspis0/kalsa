A Mixture-of-Experts (MoE) language model uses multiple specialized sub-networks called “experts” to process different parts of the input, allowing the model to be much larger than a single dense network while only activating a few experts per token. This selective activation reduces compute because only the relevant experts are used for each input, and the model’s weights are stored in a compact, sparse format. The large on-disk weight file exists because the full model’s weights are still stored, even though only a subset is used per token—this is managed via a routing mechanism that selects which experts to activate, and flash streaming enables efficient, low-latency access to the active experts during inference, allowing the model to run on devices like phones without requiring full model computation at every step.
