A Mixture-of-Experts (MoE) language model uses many specialized sub-networks called "experts" to process different parts of the input, allowing the model to be large and powerful without being fully active for every token. Instead of activating all experts for every token, only a few (e.g., 2–4) are selected based on the input, which drastically reduces compute during inference. This is possible because the model’s weights are stored in a compressed, sparse format, and the routing mechanism—often implemented via a lightweight, learned gating network—determines which experts to activate. On devices like phones, the model’s weights are stored in a compact, on-disk format (e.g., using quantization or sparsity), and only the active experts are loaded into memory, enabling efficient inference even with large total parameter counts.
