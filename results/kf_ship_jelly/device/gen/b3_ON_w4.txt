A Mixture-of-Experts (MoE) language model is a type of neural network that dynamically activates only a subset of specialized “expert” networks for each token, allowing it to scale efficiently without processing all experts for every input. This selective activation reduces compute because only a few experts are used per token, even though the model has thousands of them. The large on-disk weight file exists because the full model—every expert’s weights—are stored, and the system must still load and manage these weights during inference, even if only a few are used at a time. Routing mechanisms determine which experts to activate, and flash streaming enables the model to load and use only the necessary experts in real time, minimizing memory usage and enabling efficient deployment on devices like phones.

- Only a small number of experts are activated per token, drastically cutting compute during inference.  
- The full model’s weights are stored on disk, requiring efficient routing and flash streaming to load only the active experts for real-time inference.
