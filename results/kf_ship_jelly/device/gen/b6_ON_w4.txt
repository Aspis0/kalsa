A Mixture-of-Experts (MoE) language model uses a network of specialized “expert” subnetworks, each trained for a specific task or pattern, and activates only a subset of them for each token—this allows the model to scale up its capacity without the full cost of running all experts for every input. The key to efficiency is “routing,” where the model decides which experts to activate based on the input, and “flash streaming,” which enables the model to process tokens incrementally and only load the necessary experts from disk as needed. This means the model can have a massive on-disk weight file (because it stores many expert parameters), but at inference time, only a few are activated per token, drastically reducing compute and memory usage on devices like phones.
