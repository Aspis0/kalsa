Instead of activating all experts for every token, only a few (e.g., 2–4) are selected based on the input, which drastically reduces compute during inference. This is possible because the model’s weights are stored in a compressed, sparse format, and the routing mechanism—often implemented via a lightweight, learned gating network—determines which experts to activate.
