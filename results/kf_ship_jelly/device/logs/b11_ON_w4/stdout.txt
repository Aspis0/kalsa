User: Explain what a Mixture-of-Experts language model is, and why activating only a few experts per token can reduce compute while still needing a large on-disk weight file on a phone. Mention routing and flash streaming.
Assistant:A Mixture-of-Experts (MoE) language model uses a network of specialized “expert” subnetworks, each trained for a specific task or pattern, and activates only a subset of them for each token—this allows the model to scale up capacity without the full cost of inference. The large on-disk weight file is necessary because the model’s total parameters are huge, but only a small fraction is used per token, so the weights are stored in a compressed, sparse format. Routing mechanisms select the most relevant experts for each token, and flash streaming enables efficient, low-latency inference by processing tokens in a streaming fashion, avoiding full model loading and reducing memory usage on devices like phones.

- Only a few experts are activated per token, drastically reducing compute during inference while keeping the full model weight set stored on disk.  
- Routing layers and flash streaming allow the model to dynamically select and use only the necessary experts, enabling efficient deployment on resource-constrained devices like smartphones.
