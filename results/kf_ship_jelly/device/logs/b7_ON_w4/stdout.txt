User: Explain what a Mixture-of-Experts language model is, and why activating only a few experts per token can reduce compute while still needing a large on-disk weight file on a phone. Mention routing and flash streaming.
Assistant:A Mixture-of-Experts (MoE) language model uses many specialized "expert" networks, each trained for a specific task or pattern, and activates only a subset of them for each token to save compute. Instead of using all experts for every input, the model routes the input to a small, dynamic subset of experts via a routing mechanism, which is typically learned during training. This allows the model to be large and powerful while keeping inference efficient. On a phone, the weight file remains large because the full model’s weights are stored on disk, and only the active experts are loaded into memory during inference—this is where flash streaming and routing come in: the model streams only the necessary expert weights from disk into memory as needed, and routing decisions are made on the fly to activate just a few experts per token, reducing compute without sacrificing performance.
