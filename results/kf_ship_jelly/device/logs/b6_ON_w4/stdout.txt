The key to efficiency is “routing,” where the model decides which experts to activate based on the input, and “flash streaming,” which enables the model to process tokens incrementally and only load the necessary experts from disk as needed. This means the model can have a massive on-disk weight file (because it stores many expert parameters), but at inference time, only a few are activated per token, drastically reducing compute and memory usage on devices like phones.
